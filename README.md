# 我的作品集 | Portfolio

## 项目简介
Web开发技术课程作品集展示页面，展示三个课程项目。

## 功能特性
- 🎨 现代化深色主题设计
- 📱 完全响应式布局
- ✨ 滚动动画效果
- 📊 技能条动画
- 🔝 返回顶部按钮
- 🎯 项目卡片展示
- 🔗 在线预览 + 源码链接

## 技术栈
- HTML5
- CSS3（Flexbox、Grid、动画、渐变）
- JavaScript（ES6+，滚动监听，动画）

## 项目展示
1. **注册页** - 表单验证、响应式设计
2. **知识问答游戏** - 10道前端题，即时反馈
3. **菜单搜索器** - 实时搜索、分类筛选

## 截图替换说明
将项目截图放入 `images/` 文件夹：
- `images/register-page.png` - 注册页截图
- `images/quiz-game.png` - Quiz Game截图
- `images/menu-search.png` - 菜单搜索器截图

## 运行方式
直接在浏览器中打开 `index.html` 即可。
